# 마석 내신

마석중학교 학생의 2028학년도 고입 내신을 계산하는 반응형 웹앱입니다. 제공된 산식만 적용하며 별도 라이브러리, 설치 과정, 서버 저장소가 없습니다.

## 실행

Node.js 22 이상에서 상위 폴더의 `시작.cmd`를 실행하거나, 이 폴더의 터미널에서 실행합니다.

```powershell
node server.mjs
```

PC: http://localhost:5173

휴대폰: 같은 Wi-Fi에 연결하고 `http://PC의내부IP:5173`으로 접속합니다. Windows 방화벽에서 Node.js의 개인 네트워크 연결을 허용해야 할 수 있습니다. 개발 서버는 입력 데이터를 저장하지 않으며, 실제 외부 서비스에는 `dist/` 폴더를 HTTPS 정적 호스팅으로 배포하세요.

```powershell
npm.cmd test
```

## 계산과 예상

- 일반교과는 학기별 평균으로 산출하고, 각 학기를 0.001점 단위로 반올림한 뒤 합산합니다.
- 체육·예술은 이수한 전 학기의 A/B/C 개수를 통합합니다. 자유학기인 1학년 1학기는 제외합니다.
- 미인정 출결만 반영합니다. 지각·조퇴·결과는 학년마다 환산하고 버립니다.
- 수상은 학기당 1개, 임원활동은 월 15일 이상 활동한 중복 없는 월을 인정합니다. 한 달의 중복 직책 날짜는 합산하지 않고 실제 활동일수를 입력합니다.
- 3학년은 학기별로 생활일본어/생활중국어 중 하나만 선택합니다.
- 기본 과목은 제공된 **2026학년도 2학기** 과목 목록을 학년별로 적용한 것입니다. 실제 이수 목록과 다르면 과목 추가와 이수 체크 해제를 이용합니다.
- 미입력은 0점이나 만점으로 추정하지 않습니다. 해당 영역은 `—`로 표시합니다. 원점수·횟수·일수는 정수를 입력합니다.
- 예상 점수는 선택한 학기까지 일반교과의 득점 비율을 120점으로 환산합니다. 예: 2학년 1학기까지 32.4 / 36점 → 108 / 120점.
- 기본 입력 범위는 2학년 1학기까지입니다. 아직 성적이 없는 학기는 표시하지 않습니다. 성적 기준을 바꾸면 해당 학기까지 입력할 수 있습니다.
- 출결 입력 전에도 일반교과와 체육·예술의 교과 보정 점수는 150점 만점으로 표시합니다. 총점은 필요한 영역의 입력을 마치면 200점 만점으로 표시합니다.
- 체육·예술은 그 시점까지의 A/B/C 비율로 30점을 산출하고, 출결은 해당 시점의 학년까지 **입력을 완료한 학년**의 득점 비율로 40점을 환산합니다. 시작한 출결 행의 네 항목 중 하나라도 미입력이면 예상 출결은 산출하지 않습니다.
- 학교활동은 기준 학기까지의 현재 실적을 적용합니다. 미래 실적은 가정하지 않습니다. 임원활동은 실제 활동한 학년·학기를 직접 선택합니다. 달력의 월만으로 학기를 추정하지 않습니다.
- 영역별 현재 점수·만점·취득 비율·최종 환산 점수를 표시합니다. 자세한 산식은 `보정 계산 과정 보기`를 펼쳐 확인합니다. 예상치는 공식 확정 점수가 아닙니다.
- `목표 성적`에서 기준 학기 이후의 성취도·원점수를 입력하면, 현재 성적을 유지했을 때와 목표 성적을 달성했을 때의 총점·교과 점수·차이를 함께 표시합니다. 학기 전체에 같은 목표를 적용한 후 과목별로 수정할 수도 있습니다.
- 목표 계산은 현재까지의 실제 학기 점수와 남은 학기의 목표 점수를 합산하고, 체육·예술은 실제와 목표의 A/B/C를 통합합니다. 출결과 학교활동은 현재 보정과 같은 조건을 사용합니다. 목표 입력은 현재 성적 유지 시의 보정 결과에 영향을 주지 않습니다.

## 입력 자료 보관

입력과 결과에 집중하도록 학생 정보·예시·안내·체크리스트·백업 도구 등 부가 UI를 제거했습니다. 기본적으로 입력은 메모리에만 있으며 새로고침하면 사라집니다. 이전 화면에서 자동 저장을 켰던 자료는 계속 불러오고 저장합니다. 저장 상태는 화면 아래에 표시합니다. 기기 사이에 자동 동기화되지 않습니다.
